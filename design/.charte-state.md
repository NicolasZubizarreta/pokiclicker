## Décisions (23/10, retour de Nicolas sur les 3 directions)
- L'esprit Rouge Feu vaut pour KANTO seulement, pas pour toutes les régions ni pour la carte du monde. Johto : il partait sur un style HeartGold. Chaque région = son propre style inspiré du jeu officiel de la région.
- La carte du monde / hub = style « Atlas illustré » (direction B) : lui plaît.
- Direction C « appareil par région » : incomprise (Pokédex, Pokégear, PokéNav comme boîtiers autour de l'écran). Abandonnée comme principe ; on garde son idée de profondeur/diorama de scène.
- Charte cible : socle commun + hub atlas + thème Kanto (FRLG, base = direction A) + thème Johto (HGSS) comme preuve du système ; autres régions plus tard.
- Mockups Codex en cours : design/directions/{A,B,C}-*.html.
