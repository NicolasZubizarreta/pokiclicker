# Musiques

Toutes les pistes viennent d'OpenGameArt, licence CC0 (domaine public, attribution non requise ; elle est donnée dans Plus > Réglages > Crédits des musiques par courtoisie). Les musiques Pokémon officielles sont exclues : le dépôt est public. La V1 n'avait aucune musique, seulement les cinq sons synthétisés (déjà portés dans `src/ui/sons.ts`).

Téléchargées le 27/10/2026 avec l'accord de Nicolas. Fichiers dans `public/audio/`, réglages et association scène → piste dans `data/musiques.json` (changer une ligne de `scenes` suffit pour réaffecter une piste).
